# تجهيز نقطة البيع قبل البيع

## تم تنفيذه والتحقق منه

- التطبيق يعمل بدون إنترنت: المنتج والفاتورة محفوظان في SQLite أولاً ثم تتم المزامنة عند رجوع الشبكة.
- تجربة المستخدم أثبتت إضافة منتج بدون شبكة ثم مزامنته بنجاح.
- الواجهة العربية السودانية وRTL للتاجر ولوحة المطور جاهزة.
- قارئ QR/باركود USB أو Bluetooth يعمل ككيبورد: يمسح الرمز ثم Enter.
- إدخال أصناف من ملف `.xlsx` أو CSV محلياً مع معاينة، كشف الأخطاء، ومنع الإدخال الجزئي.
- مفتاح OpenAI مشفر ومربوط بالجهاز، وصور الفواتير لا تُرفع إلى Supabase Storage.
- ملفات الأسرار المحلية وملفات البناء لا تدخل Git.

## إضافة تاجر جديد من لوحة المطور

1. شغّل Electron في جهاز التاجر لأول مرة؛ تظهر شاشة «ربط المتجر أول مرة» وبها رقم الجهاز.
2. انسخ الرقم إلى لوحة المطور ثم افتح «أضف تاجر جديد كامل».
3. اكتب اسم المتجر وإيميل التاجر وكلمة سر أولية (12 حرفاً أو أكثر) وتاريخ انتهاء الاشتراك.
4. اضغط «أنشئ ونزّل ملف التاجر». النظام ينشئ مستخدم Supabase والمتجر والرخصة المرتبطة بالجهاز في نفس العملية.
5. أرسل ملف JSON الذي تم تنزيله للتاجر مع تطبيق Electron. الملف لا يحتوي كلمة السر ولا Service Role ولا Access Token.
6. التاجر يختار الملف من شاشة الربط، ثم يذهب إلى «الإعدادات» ويسجل دخوله بحسابه لتبدأ المزامنة.

جلسة تسجيل الدخول الحالية تبقى في الذاكرة فقط؛ بعد إغلاق التطبيق يسجل التاجر دخوله مرة أخرى. هذا يمنع حفظ كلمة السر أو توكن Supabase في ملف الإعداد.

## لازم يتم مرة واحدة قبل تسليم أول عميل

1. أنشئ مشروع Supabase للإنتاج، وطبّق migrations ثم انشر دالة `admin-license`.
2. أنشئ حساب المطور، امنحه دور `developer`، وجرّب إصدار/إلغاء/تجديد رخصة في مشروع اختبار.
3. أنشئ مستخدم Supabase منفصل لكل متجر وتأكد أن RLS يمنع المتجر من رؤية بيانات غيره.
4. اختبر على جهاز جديد: تفعيل رخصة، عمل كامل بلا نت، إعادة تشغيل البرنامج، ثم مزامنة عند توفر النت.
5. جهّز نسخة احتياطية مستقلة من قاعدة بيانات كل عميل قبل أي تحديث للتطبيق.
6. أنشئ Installer موقّع للـ Windows/macOS واختبر التثبيت والتحديث على جهاز نظيف.
7. لا تضع `SUPABASE_SERVICE_ROLE_KEY` أو مفتاح OpenAI داخل Electron أو Git أو لوحة المتصفح.

## قواعد التشغيل اليومية للتاجر

- لو النت قاطع: واصل البيع عادي؛ اضغط «زامن هسع» بعد رجوع الشبكة.
- لو ظهر صنف «بانتظار المزامنة»: لا تعيد إدخاله؛ شبّك النت ثم اعمل مزامنة.
- ملف الإكسل لازم يكون عنده على الأقل: `اسم المنتج` و`سعر البيع`.
- نفس الباركود في الإكسل يعني تحديث الصنف الموجود، بما في ذلك السعر والرصيد.
- إلغاء الرخصة من لوحة المطور يظهر في جهاز التاجر أول ما يتصل بالإنترنت؛ لا يمكن قفل جهاز يعمل بلا نت فوراً.
